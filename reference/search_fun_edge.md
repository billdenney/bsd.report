# Go to the edge

Go to the edge

## Usage

``` r
search_fun_edge(data, row, column, direction, found_edges, ...)
```

## Arguments

- data, row, column, direction, found_edges:

  See
  [`find_sub_table`](https://billdenney.github.io/bsd.report/reference/find_sub_table.md)

- ...:

  Ignored

## Value

A number for the distance to the edge.
